# JPEG完全無劣化最適化の安全設計（未実装）

- JPGの再エンコードで一般的に発生するDCT係数・量子化表変更や丸め誤差は許可しない。
- 目標はJPEGの符号化表の最適化（Huffmanの最適化等）に限定し、量子化済みDCT係数を保護すること。実装候補は、信頼できるjpegtran相当のツール。
- EXIF、XMP、ICCプロファイル、コメント、Photoshop APPn、未知のアプリケーションマーカーなどを含むファイルは、バイト単位のメタデータ保持を必須とする。
- jpegtranにはメタデータが自動的に完全保持されない構成・オプションがあり得るため、外部エンジンの出力をそのまま本番採用しない。JPEGの全マーカー構造を確認する検証器が必要。
- メタデータの完全保存と画素一致の独立デコーダ比較に合格した候補だけ別名で保存する。元ファイル置換は許可しない。
- JPEGは画素が同じであっても元のファイル全バイトが一致するとは限らない。「原本のバイト完全一致」と「画像内容が完全無劣化」を別指標として扱う。
- 画素一致が証明できないJPEG（演算・色変換差、損傷、サンプリング例外等）は必ず除外。

状態: R1.6では**設計のみ、実装0%**。
