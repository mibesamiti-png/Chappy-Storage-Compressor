# R1.4 Windows実機テスト計画

## 必須環境

- Windows 10/11、.NET 10 SDK、ローカルNTFSのテストフォルダ
- テストに使用するのは自動作成するランダムデータ、または別途複製したテスト画像だけ
- 重要な写真・動画が入ったフォルダは指定しない

## 1. 自動テスト

`RUN_TESTS.bat` を実行。`dotnet run -c Release --project tests/ChappyStorageCompressor.SmokeTests.csproj` と同等。

テストでは以下を検証するコードを追加済み（**この文書は合格を主張しない**）。

- 完全一致のSHA-256/全バイト比較、ADS/属性除外、ハードリンク統合
- 未完了ジャーナル、途中クラッシュの5停止地点、復旧状態の再検証
- R1.4の別スレッド排他拒否、容量閾値ロジック
- R1.4の正しいPNG、チャンクCRC破損、途中切れの拒否、診断前後のハッシュ一致

## 2. 手動テスト

1. `BUILD_EXE.bat` でEXEを作り、初回起動する。
2. 2個目のEXEを起動し、二重起動警告で終了するか検証。
3. テストフォルダをスキャンし、まだ統合せずリストが正しいことを確認。
4. バックアップしたテストファイルだけで統合し、元の各パスが残ることを確認。
5. テスト用PNGで診断ボタンを使用し、元ファイルSHA-256不変を確認。
6. テストプロセスを競合させて変更が拒否されることを確認。
7. テストドライブを容量不足にした状態で統合が拒否されることを確認（本番ディスクを故意に満杯にしない）。
8. 強制停止からの復旧で、退避ファイルが消えないことを確認。

## 3. 合格条件

- コンパイル成功・自動テスト全件成功
- NTFSでの各停止地点から、ファイル欠損や意図しない書き換えなし
- 容量不足と競合時は統合拒否・ログ明示
- 重要ファイルの実行はまだ別途リスク評価が必要
