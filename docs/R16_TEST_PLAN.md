# R1.6 実行テスト計画

## Windows .NET 10 SDK

1. `RUN_TESTS.bat` を隔離環境のテストフォルダで実行する。
2. 5つのPNGバリエーション（複数IDAT・Adam7・灰色16bit・パレット4bit・灰色1bit）で候補生成、チャンクCRC、元画像SHA-256不変を確認する。
3. 一括処理を1件後にキャンセルし、JSON計画と追記ログが保存されることを検証する。
4. 再実行時は残りから処理し、壊れた画像は失敗として記録、良好な候補は再生成しない。
5. 原本改変・PNG候補の改変・出力フォルダ内のジャンクション・入力出力の階層重なりを拒否する。
6. JSON/JSONLを故意に壊し、実行を安全停止することを確認する。
7. 最後に `BUILD_EXE.bat` でWindows向けEXEを作り、隔離テスト画像のみを対象にGUIを操作する。
