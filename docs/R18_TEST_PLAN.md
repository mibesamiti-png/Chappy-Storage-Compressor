# R1.8 検証計画

## C# Windows自動試験（未実行）

- JPEG小型ベースライン正常解析
- 同一JPEGのWIC画素完全一致、異なる画素の拒否
- JPEG末尾データの拒否、APP/EXIFマーカーの差分検出
- PNG記録の候補は未参照扱いにしない
- PNG候補風・利用者ファイルの未参照検出
- CSV出力は原本フォルダを変更しない
- 過去のJSONLログで参照された候補は未参照扱いにしない

`RUN_TESTS.bat` で以前のR1.1～R1.7試験も継続実行する。

## Windows手動確認が必要な項目

1. 公式libjpeg-turboの`jpegtran.exe`を導入し、8bitベースラインJPEGの候補を生成できるか。
2. EXIF/ICC/XMPとRGB画素が一致しなかった場合に候補が削除されるか。
3. 原本の最終更新時刻・内容ハッシュが変化していないか。
4. キャンセル・容量不足時に元データを変更しないか。
5. 悪意ある外部`jpegtran.exe`を信頼しないこと。公式配布物を指定する。
6. PNG監査時に不完全な進捗ログやリンク・ジャンクションを安全拒否するか。
7. 空き容量が少ないSSD/HDDで候補生成を安全保留できるか。

## 本番利用

Windowsビルド、自動テスト、実データ相当の安全性が通るまで**禁止**。R1.8では容量回復機能そのものが無効。
