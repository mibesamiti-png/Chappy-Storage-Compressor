# R1.9 検証項目

## 追加したWindows C#スモークテスト（未実行）

1. 再帰スキャンと小さいJPG優先順序
2. 改ざんされた相対パス (`..\escape.jpg`) による入力親フォルダ外参照の拒否
3. 入力と出力の入れ子関係の拒否
4. 壊れたJPGがあっても処理を記録し、原本バイト列を一切変更しない
5. 同じ出力先での追記ログからの再試行
6. 保存済み結果の監査（未採用候補は削減見込0）
7. Excel CSV数式注入のプレフィックス防止
8. 原本フォルダへのCSV出力および既存CSVの上書き拒否
9. 最終JSONL行が不完全な場合、安全停止して証拠ログを保存
10. スキャン後にファイルサイズが変わった場合 `NeedsReview` に移行

## 次にWindows上で必須となる追加テスト

- 実際の `jpegtran.exe` + 有効なJPGで候補生成→WIC全画素一致、保護メタデータ一致
- 正常な候補での中断・再開、候補改ざん時の `NeedsReview`
- 0バイトの空き・ファイルロック競合・複数プロセス・断線相当のログ破損
- 10,000件規模のキュー所要時間／メモリ／ジャーナルサイズ計測
- 使用中・編集中のJPG、同サイズ同更新日時で内容が変わった場合のSHA検査

**重要**：構造チェックが成功しても、C#コンパイルやWindows実行の安全性は証明されない。
