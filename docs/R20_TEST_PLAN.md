# R2.0 テスト手順

## Windows側で必要な環境

Windows 10/11、.NET 10 SDK、テスト用のNTFSボリューム。**本番の写真・動画は指定しないこと。**

```powershell
.\RUN_TESTS.bat
.\BUILD_EXE.bat
```

CIの実行方法: 同梱 `.github/workflows/build-windows.yml` を適切なリポジトリで起動する。

### 新しいC#テスト

- PNGとJPGを同じ入力・出力に配置し、2形式の候補レポートをまとめる。
- 削減見込を候補サイズから計算し、実際に回復した容量は0Bと表示。
- CSV出力の上書き禁止、出力先階層チェック、Excel数式注入対策。
- JPGログが途中で切れた状態の診断、元ログの完全バックアップ、末尾修復。
- 正しいJSONだが改行がない場合は行を消さず改行追加。
- 中間破損、不正な記録、計画外ファイルは修復拒否。
- いずれの操作も、ソース画像のSHA-256を変更しない。

### 現時点の限界

開発環境がLinuxで `.NET SDK` および Windows NTFSがないため、C#のビルド・スモークテストを**この環境では実行できない**。Python静的確認や参考画像検証は代替にはならない。正式な利用ゲートはWindowsでのテスト結果を確認してから判定する。
