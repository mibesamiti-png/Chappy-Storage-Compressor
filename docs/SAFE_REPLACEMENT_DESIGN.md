# 安全な原本置換のための設計ゲート（R2.0・実装前）

**この文書は将来の設計。R2.0には原本置換・原本削除を実装しない。**

## 要求

- 元フォルダのパス、拡張子、相対ディレクトリ階層は完全維持。
- PNGは展開後画素と保護すべきチャンクを照合、JPEGは展開後画素・EXIF/ICC等を照合。大切なファイルの原本バイト一致が必要なら、可逆再エンコード候補ではなくNTFS圧縮または重複排除だけを適用。
- 元ファイルの代替データストリーム、ACL、タイムスタンプ、ハードリンク数、リパース属性を検査。保証できないファイルは自動置換禁止。
- 作業ファイルを同じボリュームに安全に配置できるだけの空きがない場合は処理しない。別ボリュームの作業結果を無検証で移動して原本を消すことはしない。
- 原本と候補のサイズ・ハッシュ・必要なメタデータを置換直前に再検証。
- 置換する際は書き込み中のプロセスや競合を拒否し、復旧できる別ドライブの原本バックアップと永続ジャーナルを事前に用意。
- 途中停止地点ごとに復旧動作を定義。退避ファイルがない場合や予想外の状態は自動削除・自動上書きを拒否。
- 安全条件が満たされるまでは「分析専用」を既定とし、原本に書き込む操作を無効化。

## 置換ゲート試験

| 試験 | 合格条件 |
|---|---|
| 正常置換 | 元のパス維持、画素/メタデータ照合、実ディスク空き容量を記録 |
| 圧縮失敗 | 元データのハッシュ不変、候補のみ除去可能 |
| 残容量ゼロ / 書込み禁止 | 原本は無変更、理由を表示 |
| 元ファイルが途中更新 | スナップショット不一致で操作中止 |
| 手動・強制終了 | 各操作境界から安全に再開またはロールバック |
| 付加ストリームやACL違い | 置換拒否または保証済みコピーのみ |
| シンボリックリンク / 再解析ポイント | リンク先をたどらず拒否 |
| ハードリンク元 | 共有データを破壊する置換を禁止 |

なおWindowsの実際の空き容量は他プロセスの書き込みで変動する。予測見込は実回復量として表示しない。
