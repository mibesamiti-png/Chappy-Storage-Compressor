## 1. 「完成」の定義（v1.0）

対象は **単一ユーザーが選択したローカルNTFS上の普通のJPG/JPEG・PNG・MP4ファイル**。親フォルダを選んで以下の操作ができること。

1. **検出:** ファイルサイズ → SHA-256 → 全バイト比較で完全一致の重複を検出。形式別件数、除外・失敗理由、実行可能な対象を説明。バイト不一致の「類似画像・動画」を自動重複扱いしない。
2. **削減の事前確認:** 重複ハードリンク化による予想削減量と、JPG/PNG無劣化候補の予想削減量を**二重計上せず**表示。ファイル名・場所・権限・日時・独立編集性がどうなるか表示。利用者の明示操作がない限り原本を変更しない。
3. **容量回復:** 明示的に選択・再照合・確認した**対応ファイルだけ**重複統合またはJPG/PNGの検証済み無劣化最適化を実行。処理後にNTFS実体・データ整合性・容量差を検証し、**実際に空いた量**と**保管中バックアップが消費する量**を分けて表示する。
4. **復旧:** 完了履歴がアプリ再起動後も残り、統合で共有化したファイルを必要に応じて独立に戻せる。中断・異常終了・名前の衝突・不足容量・外部更新では安全側に停止し、証拠を消さず、何を調べるか明示する。
5. **ユーザー向け完成:** Windows WPF画面、わかりやすい警告・進捗・中断、誤操作防止、配布可能な署名/ハッシュ付き成果物（コード署名は利用可能な証明書に応じて実施、署名なしならその旨を明示）、使用手順・既知の制限、更新/復旧の案内。実際のユーザー写真・動画に対する自動破壊試験は禁止。

**v1.0の対象外（無理に全部対応しない）:** ネットワーク共有、FAT/exFAT、別ボリューム間のハードリンク統合、ドライブ直下やシステム領域、リパース/ジャンクション、共有ハードリンク、ADS、EFS、圧縮/スパース/オフライン/読み取り専用等の特殊ファイル、権限の保持を証明できない別ユーザー所有ファイル、MP4再エンコード、類似画像/映像/音声の自動統合、ZIP/7z一般解凍、任意の電源断での完全な全ファイル原子的処理保証。**未対応は検出理由を表示してスキップし、原本には触れない。** 安全性が示せない通常ファイルについても操作を拒否する。

### リリースの強制ルール

- **G2重複統合が単独合格しても本番のMergeボタンは有効にしない。** G3独立Undo/復旧、G5統合安全性、明示同意がすべてPASSになるまでロックを維持する。
- **G4画像の原本置換は独立のゲート。** PNG/JPEG候補生成が成功しても置換許可にはならない。
- **ハードリンク共有ファイルをそのまま無造作に書き換えない。** 統合後の画像最適化は、他名への影響と復旧手段を明示して、個別に独立化または専用トランザクションを通すまで禁止。
- ユーザー確認のない削除・上書き・自動復旧は禁止。ディスク残量変動や未知の外部プロセス変更、すべての障害を防げるとは主張しない。
- 本番解禁条件が満たせない場合は「完成」としない。読み取り専用版として提供できても**v1.0完成を宣言しない**。
